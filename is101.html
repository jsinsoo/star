코드 추출 상세 설명

함수
특정한 작업을 수행하도록 작성된 독립적인 코드 블록입니다. 반복 코드를 함수로 만들면 호출만으로 재사용할 수 있습니다.
함수 정의
def 함수명(매개변수): 형태로 시작하고, 함수 본문은 들여쓰기로 구분합니다.
매개 변수와 인수
인수는 호출할 때 전달하는 값이고, 매개 변수는 함수 내부에서 그 값을 받는 변수입니다.
return
함수의 처리 결과를 호출한 곳으로 돌려주고, 함수 실행을 종료합니다.

예시 코드 1: 나눗셈 함수

# 함수 정의
def divide(a, b):
    if b != 0:
        return a / b
    else:
        return '0으로 나눌 수 없습니다.'

print(divide(10, 2))
print(divide(10, 0))
줄설명
02divide라는 사용자 정의 함수를 만들고, 매개 변수 a, b를 받습니다.
03~06b가 0이 아니면 나눗셈 결과를 반환하고, 0이면 안내 문자열을 반환합니다.
08~09함수를 호출합니다. 첫 호출은 5.0, 두 번째 호출은 0으로 나눌 수 없습니다.를 출력합니다.

예시 코드 2: 중간값 찾기 함수

def find_middle_number(a, b, c):
    numbers = [a, b, c]
    numbers.sort()
    return numbers[1]

print(find_middle_number(5, 7, 3))
print(find_middle_number(10, 20, 30))
핵심설명
정의와 호출의 구분함수는 정의만으로 실행되지 않고, 6~7행처럼 호출해야 실행됩니다.
인수와 매개 변수5, 7, 3은 인수이고, 함수 내부의 a, b, c는 매개 변수입니다.
반환값정렬 후 가운데 위치인 numbers[1]을 반환합니다.
