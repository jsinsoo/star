핵심 개념 정리

재귀 구조는 큰 문제를 원래 문제와 같은 형태의 작은 하위 문제로 나누어 해결하는 구조이다. 재귀 함수는 자기 자신을 호출하며, 기본 단계와 재귀 단계가 필요하다. 반복 구조는 메모리와 속도 면에서 유리한 경우가 있고, 재귀 구조는 코드가 간결하고 논리 흐름을 명확히 표현하는 데 유리한 경우가 있다. 

def factorial(n):
    if n == 1:          # 기본 단계: 재귀 호출을 멈추는 조건
        return 1
    else:               # 재귀 단계: 문제를 더 작은 문제로 나눔
        return n * factorial(n - 1)

print(factorial(4))     # 4 * 3 * 2 * 1 = 24
  • 기본 단계: 더 이상 나눌 수 없는 가장 작은 문제를 직접 해결합니다.
  • 재귀 단계: 원래 문제를 더 작은 같은 형태의 문제로 바꾸어 자기 자신을 호출합니다.
  • 반환 과정: 기본 단계에 도달한 뒤 호출된 순서의 반대로 결과가 차례로 돌아옵니다.
