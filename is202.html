핵심 개념 정리

트리
계층 구조를 가진 비선형 데이터 구조이다. 노드와 링크로 구성되며, 루트 노드를 제외한 모든 노드는 부모 노드 하나를 가진다.
트리의 링크 수
노드가 n개인 트리의 링크 수는 n-1개이다. 트리에서는 두 노드 사이의 경로가 보통 하나만 존재한다.
이진 탐색 트리
왼쪽 서브 트리에는 작은 값, 오른쪽 서브 트리에는 큰 값을 저장하여 탐색을 빠르게 한다.
그래프
노드와 링크가 복잡하게 연결된 비선형 데이터 구조이다. 도로망, 철도망, 사회 관계망, 길찾기 등에 활용된다.
그래프 종류
방향 그래프, 무방향 그래프, 가중치 그래프, 완전 그래프 등이 있다.
그래프 탐색
DFS는 스택 또는 재귀와 관련 있고, BFS는 큐를 활용하여 가까운 노드부터 탐색한다.

코드 추출 및 상세 설명

1. 이진 탐색 트리 재귀 탐색 코드

bst = [0, 9, 6, 17, 4, 8, 12, 19, 2, 5] def search(idx, num, cnt): if idx >= len(bst) or bst[idx] == 0: print(f"{num}을(를) 찾을 수 없습니다.") return 0 elif bst[idx] == num: print(f"{num}을(를) {cnt}번 비교 후 인덱스 {idx}에서 찾았습니다.") return idx elif num < bst[idx]: return search(idx * 2, num, cnt + 1) else: return search(idx * 2 + 1, num, cnt + 1) search(1, 8, 1)
상세 설명
① bst는 이진 탐색 트리를 리스트로 표현한 것이다. 인덱스 1을 루트 노드로 사용하기 위해 0번 인덱스에는 0을 넣었다.
② search(idx, num, cnt)에서 idx는 현재 탐색 위치, num은 찾을 값, cnt는 비교 횟수이다.
③ 현재 인덱스가 리스트 범위를 넘거나 값이 0이면 빈 노드이므로 탐색 실패이다.
④ 찾을 값이 현재 노드와 같으면 탐색 성공이다.
⑤ 찾을 값이 현재 노드보다 작으면 왼쪽 자식인 idx*2로 이동한다.
⑥ 찾을 값이 현재 노드보다 크면 오른쪽 자식인 idx*2+1로 이동한다.

2. 그래프 인접 리스트와 BFS 탐색 코드

from collections import deque graph = { "A": ["B", "C"], "B": ["D", "E"], "C": ["F"], "D": [], "E": ["F"], "F": [] } def bfs(start): visited = [] q = deque([start]) while q: node = q.popleft() if node not in visited: visited.append(node) for nxt in graph[node]: if nxt not in visited: q.append(nxt) return visited print(bfs("A"))
상세 설명
① graph는 각 노드와 연결된 노드 목록을 저장한 인접 리스트이다.
② BFS는 현재 노드와 가까운 노드부터 차례로 탐색하므로 큐를 사용한다.
③ popleft()는 큐의 앞쪽 데이터를 꺼내는 동작이다.
④ 방문하지 않은 노드를 visited에 기록하고, 인접 노드를 큐에 추가한다.
⑤ 이 코드는 A에서 시작하여 가까운 노드 순서로 그래프를 탐색한다.
