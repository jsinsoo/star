1. 코드 추출 상세 설명

알고리즘의 뜻
알고리즘은 문제를 해결하기 위한 논리적인 절차와 방법을 체계적으로 표현한 것입니다. 같은 문제라도 여러 해결 방법이 있을 수 있으므로 문제 성격에 맞는 전략 선택이 중요합니다.
탐색 기반 알고리즘
가능한 해들을 탐색 공간으로 보고 그 안에서 해를 찾아갑니다. 대표 전략에는 탐욕법과 분기 한정법이 있습니다.
관계 기반 알고리즘
문제를 작은 부분 문제로 나누고 부분 문제 사이의 관계를 분석합니다. 대표 전략에는 분할 정복법과 동적 계획법이 있습니다.
알고리즘 복잡도
시간 복잡도는 연산 수의 증가 양상을, 공간 복잡도는 메모리 사용량을 의미합니다. 빅오 표기법은 입력 크기 n이 커질 때 실행 시간이 어떻게 증가하는지 단순화하여 나타냅니다.

예시 코드 1: 반복문으로 1부터 n까지 합 구하기

def total(n):
    s = 0
    for i in range(1, n + 1):
        s += i
    return s

print(total(5))

이 코드는 1부터 n까지 차례대로 더합니다. n이 커지면 반복 횟수도 n에 비례해 커지므로 시간 복잡도는 O(n)입니다.

예시 코드 2: 공식으로 1부터 n까지 합 구하기

def fast_sum(n):
    return n * (n + 1) // 2

print(fast_sum(100))

이 코드는 반복문 없이 공식을 사용합니다. 입력 n이 커져도 핵심 계산 횟수는 거의 일정하므로 O(1)로 볼 수 있습니다.
