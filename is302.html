학습 내용 요약

탐색 기반 알고리즘은 문제의 초기 상태에서 목표 상태까지 도달하는 경로 또는 해를 찾기 위해 가능한 상태를 탐색하는 방법입니다. 문제는 초기 상태, 목표 상태, 행동으로 표현할 수 있으며, 이 과정에서 발생할 수 있는 모든 가능한 상태들의 집합을 상태 공간이라고 합니다. 탐색 구조가 선형이면 선형 탐색·이진 탐색을, 비선형이면 DFS·BFS를 활용할 수 있습니다. 전체 탐색은 모든 경우를 확인하지만, 상태 공간이 크면 탐욕법, 이진 탐색, 분기 한정법처럼 탐색 공간을 줄이는 전략이 필요합니다.

코드 추출 상세 설명

# 선형 탐색: 리스트 앞에서부터 하나씩 확인 def linear_search(data, target): for i in range(len(data)): if data[i] == target: return i return -1 # 이진 탐색: 정렬된 리스트에서 중간값 기준으로 범위 축소 def binary_search(data, target): left, right = 0, len(data) - 1 while left <= right: mid = (left + right) // 2 if data[mid] == target: return mid elif data[mid] < target: left = mid + 1 else: right = mid - 1 return -1

상세 설명: 선형 탐색은 처음부터 끝까지 순서대로 확인하므로 구현이 쉽지만 데이터가 많아지면 느려집니다. 이진 탐색은 정렬된 데이터에서만 사용할 수 있으며, 한 번 비교할 때마다 탐색 범위를 절반으로 줄입니다.
