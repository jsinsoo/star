핵심 개념 정리

  • 스택(stack): 가장 최근에 입력된 데이터가 가장 먼저 출력되는 후입 선출(LIFO) 데이터 구조입니다.
  • 큐(queue): 가장 먼저 들어온 데이터가 가장 먼저 나가는 선입 선출(FIFO) 데이터 구조입니다.
  • 스택의 top: 삽입과 삭제가 일어나는 스택의 위쪽입니다. 중간에서 삽입·삭제하지 않습니다.
  • 큐의 front / rear: 삭제는 앞쪽(front), 삽입은 뒤쪽(rear)에서 이루어집니다.
  • push / pop / peek: push는 삽입, pop은 반환 후 삭제, peek은 삭제하지 않고 확인하는 연산입니다.
  • enqueue / dequeue / peek: enqueue는 큐 뒤쪽 삽입, dequeue는 큐 앞쪽 삭제, peek은 앞쪽 데이터 확인입니다.
  • 언더플로: 빈 스택이나 빈 큐에서 삭제 또는 참조를 시도할 때 발생할 수 있는 오류 상황입니다.

코드 추출 상세 설명

1. 리스트로 스택 구현

class Stack: def __init__(self): self.stack = [] def push(self, data): self.stack.append(data) def pop(self): if not self.isEmpty(): return self.stack.pop() def peek(self): if not self.isEmpty(): return self.stack[-1] def isEmpty(self): return len(self.stack) == 0
  • self.stack = []: 데이터를 저장할 빈 리스트를 만듭니다.
  • append(data): 리스트의 마지막에 데이터를 추가하므로 스택의 top에 삽입하는 push와 대응됩니다.
  • pop(): 리스트의 마지막 요소를 꺼내므로 가장 나중에 들어온 데이터를 먼저 꺼내는 LIFO가 됩니다.
  • self.stack[-1]: 마지막 요소를 삭제하지 않고 확인하므로 peek 연산입니다.

2. 리스트로 큐 구현

class Queue: def __init__(self): self.que = [] def enqueue(self, data): self.que.append(data) def dequeue(self): if not self.isEmpty(): return self.que.pop(0) def peek(self): if not self.isEmpty(): return self.que[0] def isEmpty(self): return len(self.que) == 0
  • append(data): 큐의 뒤쪽(rear)에 데이터를 추가하는 enqueue와 대응됩니다.
  • pop(0): 리스트의 첫 번째 데이터를 꺼내므로 가장 먼저 들어온 데이터가 먼저 나가는 FIFO가 됩니다.
  • self.que[0]: 큐의 앞쪽(front) 데이터를 삭제하지 않고 확인합니다.
