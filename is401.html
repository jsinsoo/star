코드 추출 상세 설명

정보과학 프로젝트는 실생활 문제를 데이터와 알고리즘으로 해결하는 과정이다. 핵심 흐름은 문제 발견 및 구조화 → 알고리즘 설계 → 프로그램 작성 → 프로그램 검증 및 디버깅 → 배포 및 유지 보수이다.

1단계 문제 발견 및 구조화
해결할 문제를 명확히 정의하고, 수집한 데이터를 바탕으로 문제를 작은 단위로 나눈다.
2단계 알고리즘 설계
문제 해결 절차를 정하고, 적합한 알고리즘과 데이터 구조를 선택한다.
3단계 프로그램 작성
설계한 알고리즘을 실제 코드로 구현한다. 가독성과 유지 보수성을 고려한다.
4단계 검증 및 디버깅
프로그램이 올바르게 동작하는지 확인하고 오류를 수정한다.
배포 및 유지 보수
사용자가 사용할 수 있도록 배포하고, 버그 수정·기능 개선·문서화를 지속한다.

예시 코드 1: 프로젝트 단계 출력

steps = [
    '문제 발견 및 구조화',
    '알고리즘 설계',
    '프로그램 작성',
    '프로그램 검증 및 디버깅',
    '배포 및 유지 보수'
]

for i, step in enumerate(steps, 1):
    print(f'{i}단계: {step}')

리스트에 프로젝트 단계를 저장하고 enumerate를 사용하여 단계 번호와 내용을 함께 출력한다.

예시 코드 2: 급식 잔반 최소화 데이터 구조

menu_data = {
    '비빔밥': {'선호도': 9, '예상잔반': 3},
    '생선구이': {'선호도': 5, '예상잔반': 7},
    '카레라이스': {'선호도': 8, '예상잔반': 4}
}

best = min(menu_data, key=lambda m: menu_data[m]['예상잔반'])
print('잔반이 가장 적은 메뉴:', best)

딕셔너리로 메뉴별 데이터를 저장하고, 예상 잔반량이 가장 작은 메뉴를 찾는다.

예시 코드 3: 검증 함수

def validate_amount(value):
    if value < 0:
        return '오류: 음수 데이터'
    return '정상 데이터'

print(validate_amount(12))
print(validate_amount(-3))

입력 데이터가 유효한지 확인하는 간단한 검증 함수이다. 프로젝트에서는 입력값 검증이 디버깅의 출발점이 된다.
