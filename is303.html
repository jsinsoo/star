관계 기반 알고리즘은 복잡한 전체 문제를 작은 부분 문제로 나누고, 전체 문제와 부분 문제 사이의 관계를 찾아 해결하는 방법입니다. 대표적으로 분할 정복법과 동적 계획법이 있습니다.

문제 분해관계식재귀분할 정복동적 계획법

예시 1. 1부터 n까지 합

def f(n):
    if n == 1:
        return 1
    else:
        return f(n - 1) + n

print(f(10))

전체 문제 f(n)은 부분 문제 f(n-1)에 n을 더하는 관계로 표현됩니다. 종료 조건 f(1)=1이 있어야 재귀 호출이 멈춥니다. 실행 결과는 55입니다.

예시 2. 하노이 탑 이동 횟수

def hanoi_count(n):
    if n == 1:
        return 1
    return 2 * hanoi_count(n - 1) + 1

print(hanoi_count(3))

원반 n개를 옮기려면 n-1개를 보조 기둥으로 옮기고, 가장 큰 원반 1개를 목표 기둥으로 옮긴 뒤, 다시 n-1개를 목표 기둥으로 옮깁니다. 따라서 T(n)=2T(n-1)+1입니다.

예시 3. 동적 계획법 계단 오르기

def stair(n):
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

print(stair(5))

한 번에 1칸 또는 2칸 오를 수 있으므로 n번째 계단에 도달하는 방법은 f(n-1)+f(n-2)입니다. 이미 계산한 값을 dp에 저장해 중복 계산을 줄입니다.
